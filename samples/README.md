# Audio samples

`index.html` is a self-contained page: open it in a browser to compare systems
side by side. It makes no external requests.

Ten held-out utterances from the voiced test split, decoded by four EMG front ends
through an identical translator and an identical frozen speech decoder. Only the EMG
front end differs between columns. Ground truth is the original recording.

Audio is 16 kHz, 16-bit PCM, not re-encoded through a second lossy codec.

Note: these ten were selected for perceptual quality (highest UTMOS averaged over the
four EMG systems) and are therefore not a uniform random sample of the test split.
